# Profile gallery images

1. Copy optimized `.jpg`, `.png`, `.webp`, or `.avif` images into this folder.
2. Open `lib/profile-data.ts`.
3. Add `src: '/gallery/your-image.jpg'` to the matching gallery entry.
4. Replace the demo title, context, alt text, and optional date.

Use descriptive filenames, meaningful alt text, and images under roughly 500 KB when practical.
